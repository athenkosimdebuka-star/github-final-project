Simple Interest Calculator
This repository contains the README file for the GitHub Final Project, a calculator that calculates simple interest given the principal amount, annual rate of interest, and time period in years.

Input
P — Principal amount
T — Time period in years
R — Annual rate of interest
Output
Simple Interest = (P × T × R) / 100

The calculator uses the simple interest formula to calculate the interest based on the principal amount, annual interest rate, and time period.
